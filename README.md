# Interactive Storybook Birthday Invitation

A mobile-first interactive birthday invitation designed as a digital storybook. Built with HTML, CSS and JavaScript, with animated page transitions, personalised content and background audio.

## Live Demo

[View the interactive invitation](monumental-panda-2401c3.netlify.app)

> The invitation text is in Croatian because it was created for a Croatian-speaking audience. All text, colours, images and event details can be customised for other languages and clients.

## Features

- Mobile-first responsive design
- Interactive storybook experience
- Animated page transitions
- Personalised event information
- Custom photo section
- Background music and sound effects
- Automatic music fade-out on the final page
- Easy content customisation

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Customisation

The invitation can be customised with:

- Name and age
- Date and time
- Venue
- Personal message
- Images
- Colours
- Music
- Language
